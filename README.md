# HexNook IME

HexNook IME 的发布仓库。到 [Releases](https://github.com/15055334413le-ops/HexNook-IME-Releases/releases/latest) 下载最新版安装包 `CorspiiIME-Setup-x64.exe`（64 位 Windows 10 / 11）。同一版本另附内容相同的旧名副本 `HexNookIME-Setup.exe`，供 0.9.68 及更早的版本在软件内升级。0.9.69 起的版本另附 Windows 7 SP1 x64 安装包 `CorspiiIME-Setup-win7-x64.exe`（及其签名清单 `setup-win7.txt` / `setup-win7.sig`），Windows 7 / 8 / 8.1 请使用该安装包。
