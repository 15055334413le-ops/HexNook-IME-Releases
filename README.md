# Hex Nook IME 在线词库

Hex Nook IME 输入法的扩展词库，按首音节切成小文件，输入法打字时按需读取；`full.txt` 是整份词库，供下载到本机。
词条内容来自以下开源项目，没有修改，各自的许可证见对应目录的 LICENSE：

| 目录 | 来源 | 许可证 |
| --- | --- | --- |
| v2/rime-ice | [雾凇拼音](https://github.com/iDvel/rime-ice) | GPL-3.0 |
| v2/thuocl | [清华大学开放中文词库 THUOCL](https://github.com/thunlp/THUOCL) | MIT |
| v2/zhwiki | [中文维基百科词条](https://github.com/felixonmars/fcitx5-pinyin-zhwiki) | CC BY-SA 4.0 |

每周自动同步一次。
